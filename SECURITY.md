# Security policy

Report exploitable vulnerabilities privately through the contact method on the repository owner's GitHub profile rather than in public issues.

Include affected commit/version, environment, reproduction steps, impact, and mitigation if known. Do not include credentials, private prompts, or personal data.

HeadlessAi is early development; do not assume it is production-hardened for untrusted endpoint configuration or privileged agent workflows.
