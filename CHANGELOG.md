# Changelog

All notable changes to HeadlessAi are recorded here. This repository is in early development; entries describe repository state, not a promise of compatibility or a published NuGet release.

## Unreleased

- Established the .NET 8 library, test project, benchmark project, and solution.
- Added endpoint profiles, reusable agent templates, normalized invocation contracts, request-time headers, cancellation, timeouts, and response bounds.
- Added raw-text, delegate-based, JSON, OpenAI Responses, Gemini generateContent, and Anthropic Messages adapters.
- Added fixture-based tests, BenchmarkDotNet baselines, CI coverage/pack workflow, architecture and security documentation, use cases, and a measurement plan.
- Documented that ProtocolAi and GrammarAi are optional and token/drift/accuracy improvements require evidence.
- NuGet publication remains disabled unless explicitly approved.
